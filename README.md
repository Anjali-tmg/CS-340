How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?

One of the most important things I learned in this course is how to write programs that are maintainable, readable, and adaptable. While creating the CRUD Python module in Project One, I organized the database operations into separate methods for creating, reading, updating, and deleting records. This made the code easier to understand and prevented me from repeating the same database connection code throughout the dashboard. When I started Project Two, I was able to reuse the same CRUD module to connect the dashboard widgets to MongoDB instead of writing new database code. This saved time, made debugging easier, and allowed me to focus on building the dashboard. In the future, I could reuse this CRUD module in other projects that use MongoDB, such as inventory systems, employee databases, or other applications that need to store and manage data.


How do you approach a problem as a computer scientist? Consider how you approached the database or dashboard requirements that Grazioso Salvare requested. How did your approach to this project differ from previous assignments in other courses? What techniques or strategies would you use in the future to create databases to meet other client requests?

To solve this project, I approached it step by step. First, I made sure the MongoDB database was working correctly and that the CRUD module could retrieve the required records. After that, I connected the module to the dashboard and tested each feature, including the data table, charts, and map, to make sure they displayed the correct information. This project was different from many of my previous assignments because it combined several technologies instead of focusing on only one programming language or concept. I had to work with Python, MongoDB, Dash, and data visualization together. In future projects, I would continue breaking large problems into smaller tasks, testing each part individually, and designing the database carefully before writing the application.
